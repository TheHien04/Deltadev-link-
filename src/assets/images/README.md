# Storefront images

Place optimized product photos here. The site ships with SVG placeholders so layout never depends on missing JPEGs.

| File | Use |
| --- | --- |
| `product-classic.svg` | Heritage Classic / hero |
| `product-gift.svg` | Gift box |
| `product-lean.svg` | Lean recipe |
| `certificate.svg` | Quality section |
| `favicon.svg` | Favicon and PWA icon |

When you have photography, export WebP + JPEG at 1200px on the long edge, keep file size under 200KB, and update `src` attributes in `index.html`.
